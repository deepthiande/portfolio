IoT Project

Health Monitoring System using NodeMCU

Project Overview

Developed an IoT-based Health Monitoring System using NodeMCU to monitor heart rate, body temperature, and SpO₂ in real time. This system was designed to provide continuous patient telemetry and immediate auditory alarms upon detecting critical vital sign anomalies.

Key Implemented Features
  • Sensor Integration: Combined MAX30100 optical pulse oximetry sensor and LM35 analog temperature sensor.
  • Real-Time Data Collection: Programmed microcontrollers to acquire, filter, and calibrate physiological signals.
  • OLED Display: Rendered clear real-time numeric readouts of BPM, SpO₂ percentage, and temperature in °C.
  • Active Buzzer Alarm: Integrated hardware buzzer triggering emergency alerts when vitals exceed configured safety thresholds.
  • Wireless Data Monitoring: Streamed sensor packets wirelessly using NodeMCU's built-in Wi-Fi module for remote caregiver monitoring.

Project Overview
